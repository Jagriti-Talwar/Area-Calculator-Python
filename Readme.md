# Area Calculator

## Introduction

Area Calculator is a simple Python-based program that calculates the area of different geometric shapes. The user can select a shape from the menu and enter the required dimensions to get the calculated area.

## Features

- Simple menu-driven program
- Calculates area of multiple shapes
- Takes input from the user
- Displays the calculated area
- Allows the user to perform multiple calculations

## Shapes Included

The program calculates the area of:

1. Circle
2. Rectangle
3. Square
4. Parallelogram
5. Triangle
6. Rhombus
7. Trapezium
8. Ellipse

## Technologies Used

- Python
- Basic Python programming concepts
- Conditional statements
- Loops
- User input and output

## How to Run

1. Make sure Python is installed on your computer.
2. Open the file `area_calculator.py`.
3. Run the program using Python.
4. Select a shape from the menu.
5. Enter the required dimensions.
6. The program displays the calculated area.

## Project Objective

The objective of this project is to apply basic Python programming concepts to create a useful menu-driven application for calculating the areas of different geometric shapes.
